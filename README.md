# SabKuch AI — Boutique AI Technology Studio

> **"Same Intelligence. More Possibilities."**  
> AI for a better tomorrow.

A production-quality, responsive portfolio and inquiry website for **SabKuch AI**, a boutique AI technology studio that collaborates with brands to solve real-world problems through practical AI solutions—from intelligent websites and chatbots to automation systems and AI agents.

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Vanilla CSS with custom design tokens (`tokens.css`, `typography.css`, `layout.css`, `components.css`, `animations.css`)
- **Icons**: Lucide React
- **Brand Palette**:
  - Near-Black Foundation (`#060707`, `#000000`)
  - Crisp Off-White Typography (`#f5f7f6`)
  - Reference-derived Neon Lime Accent (`#85fe01`)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### 3. Build for Production
```bash
npm run build
```
The output will be built into the `dist/` directory.

---

## ☁️ Deployment on Vercel

1. Import this repository into Vercel.
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**.
